# Virtuosis Voice Biomarker API

REST API from Virtuosis AI (an EPFL spinoff) providing AI-based voice biomarker analysis that detects health disorders from short audio recordings. Analysis families include Wellbeing (stress, anxiety, depression), Parkinson's, Alzheimer's/MCI, and Communication Coach. Delivered as CE-marked software as a medical device with Bearer-token authentication.

- **Provider:** https://www.virtuosis.ai/

## APIs

- **Virtuosis Voice Biomarker REST API** — REST API (v1.3) for voice biomarker analysis: create accounts, upload Base64-encoded audio recordings, poll analysis results, check usage, and health checks. Uses Bearer-token authentication. Documented via Fern with a public OpenAPI contract and agent-native surfaces (hosted docs MCP server and llms.txt). (`https://api.virtuosis.ai/v1.3`)

> All referenced artifacts (docs portal, OpenAPI JSON/YAML, llms.txt, llms-full.txt, and hosted MCP server) were independently confirmed live during research. The MCP server is a Fern docs MCP server (streamable-http) exposing only a read-only searchDocs tool over documentation; it does NOT wrap the biomarker API endpoints. A local install hint exists (claude mcp add --transport http ... https://docs.virtuosis.ai/_mcp/server) but the endpoint itself is publicly hosted, so it qualifies as an MCPServer. The submitted apis.json and /.well-known/api-catalog could not be fetched directly, but all their referenced artifacts were verified. Note: one endpoint reference page still renders v1.2 examples (https://api.virtuosis.ai/v1.2/recordings) alongside the current v1.3. No AsyncAPI, GraphQL, Postman collection, or published agent skills were found. Medical insights (Parkinson's/Alzheimer's) require manual validation before access.
