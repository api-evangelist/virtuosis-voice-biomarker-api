# Virtuosis Voice Biomarker API

Virtuosis exposes a REST API for acoustic/voice-biomarker analysis of speech recordings, delivering health, wellbeing, and communication insights. Applications upload Base64-encoded audio and poll for analysis results across types such as wellbeing, parkinsons, alzheimers, and communication_coach. Access to live API calls requires an approved organization and API key, while documentation, OpenAPI specs, llms.txt, and a hosted MCP server are publicly reachable.
